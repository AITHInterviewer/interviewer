---
description: UI Kit Extractor & Refactor
---

**Role:** Senior Frontend Architect (Next.js, Tailwind, TypeScript).

**Task:** Проанализировать папку страницы и выполнить глубокий рефакторинг с выделением UI Kit.

**Step-by-Step Instructions:**

1. **Analysis & Audit:**
* Просканируй все файлы в целевой папке. Найди повторяющиеся паттерны в верстке: инпуты, кнопки, заголовки секций и обертки.
* Особое внимание удели хедерам. Сейчас они разные. Твоя задача — привести их к единому лаконичному виду.


2. **Component Extraction (UI Kit Creation):**
* Создай в корне проекта папку `src/components/ui` (если её нет).
* Выдели следующие компоненты:
* `Typography.tsx` (единый компонент для заголовков и текстов).
* `Input.tsx` (стандартизированное поле ввода).
* `SectionHeader.tsx` (компактный заголовок страницы/секции без описаний, минималистичный дизайн).


* Все компоненты должны быть **функциональными (Pure Components)**, принимать только нужные `props` и быть максимально независимыми.


3. **Header Standardization:**
* Перепиши все заголовки страниц. Используй компактный стиль: только название страницы, иконка назад (если есть) и, возможно, текущий баланс/статус. **Удали длинные текстовые описания под заголовками**, чтобы сэкономить место на экране.


4. **Refactoring the Page:**
* Замени в исходных файлах страниц "грязную" верстку на импортированные компоненты из новой папки `ui`.
* Удали неиспользуемые импорты и стили.


5. **Best Practices Implementation:**
* **Atomic Design (Light):** разделяй атомы (кнопки/инпуты) и молекулы (формы).
* **Tailwind Efficiency:** используй `clsx` или `tailwind-merge` для объединения классов.
* **Type Safety:** каждый компонент должен иметь четкий интерфейс `Props` на TypeScript.
* **Single Responsibility:** один компонент — одна задача. Не перегружай UI-кит логикой API.
* **Accessibility (A11y):** добавь базовые `aria-label` и правильные теги (h1, h2, button).



**Output Expectation:**

* Список созданных файлов в `components/ui`.
* Обновленный код страниц с чистыми импортами.
* Краткий отчет о том, что было оптимизировано.
