# Обзор экранов, 6 сентября 2026

`screens.html` — 29 экранов кабинета и кандидатского пути, снятых на коде ветки `feat/ui-on-main`.
Открывать файлом в браузере: картинки вшиты внутрь, ничего доустанавливать не нужно.
Отдельные кадры в репозитории не держим — они пересобираются командой ниже за минуту.

Под каждым экраном подпись: что на нём видно и что с ним делать. Зелёным помечено сделанное,
жёлтым — оставшееся. В конце страницы разбор, как доделать остальное, и что упирается в бэкенд.

## Как пересобрать

Скриншоты снимаются без бэкенда: ответы API подменяются фикстурами.

```bash
cd frontend && npm run dev
cd tools/live-view && node mock-shots.mjs board=/vacancies/v-python report=/vacancies/v-python/candidates/i-lida
```

Мок кандидата лежит в `tools/live-view/fixtures.mjs`: Лидия Орлова, вакансия Middle+ Python
Developer, пять требований, пять вопросов, четыре расшифровки. Один вопрос без ответа и два
требования без вопроса оставлены нарочно, чтобы на экранах была видна и норма, и дыра.

Обход маршрутов и проверка ссылок:

```bash
cd tools/live-view && node route-check.mjs
```
