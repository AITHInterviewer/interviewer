# Quickstart: 006-prototype-ux-pass

## Prerequisites

```bash
cd frontend
npm install
cp -n .env.example .env
npm run dev
```

Открыть `http://localhost:3000` (или порт, который напечатает Next, если 3000 занят). Бэкенд не нужен.

## Проверка входа и попапа

1. Корень открывает `/login`.
2. Видны семь карточек с именами (Анна, Алексей, Игорь, Дмитрий, Никита, Лидия, Ольга), не «кандидат №1».
3. Клик по рекрутеру открывает попап, не сразу список вакансий.
4. «Назад к ролям» или Esc возвращает на вход.
5. «Продолжить» ведёт на `/vacancies`.
6. В шапке есть «К выбору роли».

Повторить попап для эксперта, менеджера и Лидии: каждый home из [contracts/demo-roles.md](./contracts/demo-roles.md).

## Проверка канбана и списка

1. Войти как рекрутер → открыть Middle+ Python.
2. На доске пять колонок, ни одна не «Пока пусто».
3. Лидия, Дмитрий, Никита в «Отчёт готов» и открывают отчёт.
4. Марина / Павел / Елена / Олег на своих стадиях отчёт не открывают.
5. Переключатель «Список»: те же люди, стадия подписана.

## Проверка Нильсена на рабочем пути

1. Кандидат Лидия: первый кадр не пустой; нет мёртвой «Напомнить позже»; есть «К выбору роли».
2. Новая вакансия: на шагах есть Назад или Отмена.
3. Отчёт Лидии: подсказка у «недостаточно данных»; «Не продвигать» через попап, не системный confirm.
4. 403 / 404 / истёкшая ссылка по-прежнему объясняют, куда идти.

## Проверка единообразия

1. Заголовки внутренних страниц одного кегля (`PageHeader`).
2. Primary-кнопки одного акцента в светлой и тёмной теме (переключить луну).
3. Пилот `/expert`, `/brief/python-middle`, `/i/lida/result`: бейдж «Пилот», нет пустого кадра, на результате названия требований, не `async`/`sql`.

## Команды

```bash
cd frontend
npm run lint
npm run build
```
