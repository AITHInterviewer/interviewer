# Контракт дизайн-системы (UI)

Это контракт внешнего вида и chrome. Маршруты не меняем: см. `specs/005-evidence-interview-ui/contracts/ui-routes.md`.

## Design read

Продуктовое демо Napoleon, не лендинг. Сохраняем бренд. Выравниваем шкалу, не рисуем новый стиль.

## Токены (источник: `frontend/app/globals.css`)

Цвета и радиусы уже есть и MUST остаться семантическими именами:

- поверхность: `--canvas`, `--surface`, `--surface-raised`, `--surface-muted`, `--surface-selected`
- текст: `--ink`, `--ink-secondary`, `--ink-tertiary`
- линия: `--border`, `--border-strong`
- акцент: `--accent`, `--accent-hover` (light кобальт, dark светлее тот же акцент)
- смысл: `--positive`, `--warning`, `--danger` (+ soft)
- радиусы: `--radius-control` 8px, `--radius-panel` 12px, `--radius-pill` 999px
- шрифт: `--font-sans` Helvetica Neue / system; не Inter

### Шкала текста (добавить переменные, убрать разброс h1)

| Токен | Размер | Где |
|---|---|---|
| `--text-path` | 12px | хлебные крошки, «демо-вход» |
| `--text-meta` | 13px | колонка канбана, подписи, VersionTag вторичен |
| `--text-body` | 15px | основной текст |
| `--text-h2` | 16px | заголовок секции, drawer, колонки как группа |
| `--text-h1` | 32px | `PageHeader` и заголовок шага кандидата (согласие, проверка, готово) |
| `--text-display` | 32px | только формулировка вопроса C6/C7; тот же кегль, жирнее/длиннее строка |

Запрещено: разовые `fontSize: 20 | 28 | 34 | 36 | 42` в JSX. Заголовок AiNote = `--text-h2` или отдельный класс `.ai-note__title` на `--text-h2`, не 20px инлайн.

Различимость экранов: `AppShell` vs `CandidateShell`, «Доска» vs «Список», состояния loading/empty/error. Не третий шрифт и не второй акцент.

## Обязательные паттерны

| Паттерн | Правило |
|---|---|
| `PageHeader` | `.path` + `h1` ( `--text-h1` ) + опционально `.page-title__description` |
| Кнопка | только `Button`: primary / secondary / ghost / text. Primary = `--accent` |
| Попап | существующий `Modal` (оверлей, Esc, крестик, «Назад») |
| Тост | `ToastStack`; не `alert` / `confirm` |
| Статус требования | `StatusBadge` |
| Пилот | `PilotBadge` на каждом пилот-маршруте |
| Смена роли | одна подпись «К выбору роли» в топбаре AppShell и в подвале CandidateShell |

## Состояния

Любой маршрут 005 после 006:

1. loading: скелетон той же сетки, не пустая страница
2. ready
3. empty: заголовок + «в этом демо пусто» + действие если есть
4. error: что / почему / куда дальше

Вкладки «Черновики / На проверке / Архив» без строк используют empty, не молчаливую таблицу.

## Доска и список

Один экран `R3`, переключатель «Доска» / «Список» остаётся.

- Доска: пять колонок, в каждой ≥1 `PipelineCard`.
- Список: те же люди, колонка или группировка «стадия», не только те, у кого есть отчёт.

## Что не входит

Новые npm, Motion, смена логотипа, второй акцент «для кандидата», декоративные градиенты, смена URL.
