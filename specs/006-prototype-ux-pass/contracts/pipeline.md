# Контракт канбана и списка

Экран: `/vacancies/python-middle` (R3). Переключатель «Доска» / «Список» сохраняется.

## Колонки доски

Порядок фиксирован:

1. Приглашены (`invited`)
2. Проходят (`inProgress`)
3. Обработка (`processing`)
4. Отчёт готов (`reportReady`)
5. Решено (`decided`)

Пустая колонка с одной фразой «Пока пусто» после 006 недопустима.

## Карточки

Поля см. [data-model.md](../data-model.md) → `PipelineCard`.

Клик:

- `reportReady` + канон → `/vacancies/python-middle/candidates/{id}`
- остальные стадии → отчёт не открывать; карточка информативная (на ранних можно показать тултип/подпись «отчёта ещё нет»)

## Список

Те же семь людей (3 канона + 4 воронки). У каждой строки видна стадия словами. Строки без отчёта не выглядят сломанной ссылкой: либо без ссылки, либо «отчёта ещё нет».

## Счётчик на списке вакансий (R1)

Не `2/1/3/0`. Формат вроде: «приглашены 1 · проходят 1 · обработка 1 · отчёты 3 · решено 1» (цифры по факту сида).
