# Quickstart: 005-evidence-interview-ui

## Prerequisites

```bash
cd frontend
npm install
cp -n .env.example .env
npm run dev
```

Открыть `http://localhost:3000`.

Бэкенд не обязателен. Health-check на главной больше не показывается как продукт.

## Demo path (жюри)

1. `/login` → «Войти как кандидат №3»
2. C1 «Начать» → согласие → проверка → правила → тренировка (можно пройти кликами) → вопрос 3
3. На вопросе 3 сохранить ответ → уточнение C7 → после 5-го или скип демо-переход на C9
4. Назад `/login` → рекрутер
5. Вакансия → канбан → Лидия Орлова → отчёт
6. Drawer по требованию с «Недостаточно данных»
7. «Запросить доп. ответ» → тост
8. «Передать менеджеру»
9. «Посмотреть как менеджер» → M4

## Checks

- `npm run lint`
- `npm run build`
- Нет процентов уверенности в DOM
- Нет слов «списывание» / «обман» / «подозрительно»
- Тема светлая/тёмная не ломает контраст кнопок
